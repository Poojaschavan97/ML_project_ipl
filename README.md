IPL Match Outcome Prediction & Analytics Platform
Python • Pandas • Scikit-learn • Power BI • Streamlit
An end-to-end data analytics and machine learning project on Indian Premier League data — covering exploratory analysis, interactive dashboards, and match outcome prediction.

What This Project Does
IPL datasets contain rich information about teams, players, venues, and match outcomes. This project answers real business-style questions a cricket analyst or sports broadcaster would care about:

Which teams consistently outperform at specific venues?
Who are the highest-impact batsmen and bowlers across seasons?
Can we predict match outcomes based on pre-match features?


Key Findings

Venue significantly affects win probability — certain home grounds show 60%+ win rates for the hosting franchise
Top-order batting consistency is a stronger predictor of match wins than bowling economy in powerplay overs
Season-wise trends reveal a measurable shift in batting strike rates post-2019, likely driven by rule changes
Match outcome prediction model trained on historical data — evaluated on accuracy, precision, and recall
